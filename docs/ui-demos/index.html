What I'd change

Grouped by page. Items marked demo are mocked up above; the rest are quick written recommendations.

Login / Signup
  • Add the signature lattice + brand cover — the app's most identifying visual is absent from its front door. demo
  • Lift form hierarchy: heavier labels, 14px fields, a real focus ring.
  • Replace the abstract tagline "Reference table mapping."
Dashboard
  • De-densify the status line — the 7-field inline row is hard to scan; split into a short summary. demo
  • Feature the coverage KPI; unify skeleton radii with live cards.
  • Copy: drop "messy" (§Language) — say "source values".
Review
  • Stronger active filter pill (solid accent, not a faint wash). demo
  • Move match confidence onto the workflow palette — teal/ochre/neutral, not out-of-brand blue/red. demo
  • Standardize every empty state to one emoji + one directive.
  • Consolidate the two footer error zones into one.
Sources
  • Copy: "No sources wired yet" → "No sources connected yet".
  • Give the empty state a clear primary ("Browse catalog") over the secondary settings link.
  • Elevate the "values await a decision → Review" pointer above the fold.
Settings
  • Route every card through Panel — Danger and Warehouse hand-roll border + bg cards that drift from the system.
  • Rename the "Matching" section to "Mapping" for users.
  • Add a page title per section — settings pages currently start cold with a bare form.
  • Swap the heavy role-popover shadow for the border + elevated-surface pattern.
Integrations
  • Turn the "N duplicate URLs" note into a warn banner above the table.
  • Add a copy affordance next to masked secrets/tokens; drop kid= jargon.
  • Render "never" / null last-delivery as an "—" placeholder.
Account
  • Reuse the existing RoleBadge in Memberships instead of inline mono text.
  • Couple the autosave status inline with its field label.
  • Give the empty-membership state an action ("Ask an admin to add you").
Admin
  • Thin the 6-column Workspaces table (2-tier rows or drop last-activity) for scannability.
  • Fix avatar contrast — accent initials on an accent-soft fill are low-contrast.
  • Add Enter-to-search on the Users / Audit search inputs.
  • Extract one SuperAdminBadge; the Users and Audit variants differ.
