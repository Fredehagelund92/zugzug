4 Removing a database with dependent sources
Remove finance_eu?
This database powers 3 sources across 2 dimensions. Removing it unbinds them. Canonical values stay — only the source binding goes away. You can re-bind to a different database later.
Dependents

Sources will be removed from dimension_source in the same transaction as the database row. source_stat rows are dropped too. Audit gets warehouse.database.remove + per-source dimension.source.unbind entries.
admin only Destructive button enables once the checkbox is ticked. Editors hit a 409 here and see this same dialog with the button replaced by "Ask an admin to confirm".
