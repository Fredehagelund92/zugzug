# UI/UX Polish Pass — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the reviewed UI/UX polish across every page of the Zugzug app on the `polish` branch, in a series of independently-shippable phases.

**Architecture:** Static light-mode mockups already exist under `docs/ui-demos/` and are the pixel-level visual spec for the three demoed pages (Login, Dashboard, Review). Each phase below maps to one focused commit/PR off `polish`. Visual rebuilds port a demo into React using the existing token-backed Tailwind utilities (`text-ink`, `bg-surface`, `border-line`, etc.) and existing primitives (`Panel`, `EmptyState`, `Button`, `Badge`, `RoleBadge`). Behavioural and copy changes are guarded by tests in the existing Vitest + Testing-Library setup; purely visual changes are gated by a headless-Chrome screenshot compared against the corresponding demo file.

**Tech Stack:** Vite + React 18 + React Router, Tailwind v4 (tokens aliased from `app/src/tokens.css`), Vitest + @testing-library/react. Run tests from `app/` with `bun run test` (alias for `vitest run`). Type-check with `bun run typecheck`.

## Global Constraints

- **One accent per view.** Rose `--accent` (#d6336c) only. Amber `--accent-2` is secondary/source-lamp, never a CTA.
- **Workflow semantics, not generic status.** `--ak-committed` teal = published; `--ak-staged` ochre = draft. Never reuse `ok`/`warn` for these.
- **8px spacing grid.** Compose on `--ak-space-*`; no 5/7/13px gaps.
- **Square-mode is permanent.** `--r-sm/--r/--r-lg` are 0; only pills round. Author radii semantically anyway (`rounded-lg` for containers).
- **Never hardcode brand color.** Use token utilities / `var(--token)`.
- **Mono is for identifiers only.** No English prose in JetBrains Mono.
- **Vocabulary (CLAUDE.md §5 / CONTEXT.md).** Plain words: table, record, source value, mapping, draft, working copy, publish, Review, workspace, member. Banned in user-facing strings: `canonical, raw, triage, master, golden, commit, sync, tenant, matching`. Enforced by `app/test/vocabulary-gate.test.ts` — extend its `FILES` list for every page this plan touches.
- **Empty states:** single emoji glyph + one-line directive on `text-ink`. No paragraphs, no illustrations, no button unless fixable in one action.
- **Panel is the one in-page container** — border + `bg-surface`, no shadow. Shadow signals "floating above the page" (overlays only).
- **Verification approach:** copy/behaviour changes → a Vitest test (red→green). Pure-visual changes → screenshot via the command in the Appendix, eyeballed against `docs/ui-demos/<file>.html`. Every task ends green on `bun run test` + `bun run typecheck`.
- **Respect `prefers-reduced-motion` and keyboard focus.** No task may remove a visible focus ring.
