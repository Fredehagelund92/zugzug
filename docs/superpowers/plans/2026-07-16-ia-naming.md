# IA / Naming Vocabulary Sweep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align the UI vocabulary with the grilled IA decisions and the project's own glossary — rename the tab labels **"Match values" → "Map values"** and **"Wired sources" → "Sources"**, and reserve **"Review"** for the cross-table inbox by renaming the in-surface pre-publish panel to a **publish preview** ("Preview" / "Staged to publish").

**Architecture:** A pure user-facing string sweep — no behavior change. One anchor render test on `ModeStrip` (the primary surface) provides a real red→green cycle; the remaining occurrences are mechanical string edits verified by a grep gate + the type/lint gates. The nav "Review" destination (Triage) is explicitly left untouched.

**Tech Stack:** TypeScript, React, Vitest + `@testing-library/react`. Run from the `app/` workspace.

**Plan series:** Plan **7 of 7** (final). Independent of the other plans; depends only on strings on `main`. `CLAUDE.md` §5 mandates "map/mapping" over "match" and reserving "Review" for the inbox — this is that mandate applied.

- [ ] **Step 1: Write the failing test**

Create `app/src/components/modes/ModeStrip.test.tsx`:

```tsx
import { describe, it, expect, vi } from "vitest";
import { render, fireEvent } from "@testing-library/react";
import { ModeStrip } from "./ModeStrip";

describe("ModeStrip", () => {
  it("renders the map-values vocabulary — Records / Map values / Sources", () => {
    const { getByText, queryByText } = render(
      <ModeStrip modes={["records", "match", "sources"]} active="match" onSelect={() => {}} />,
    );
    expect(getByText("Records")).toBeTruthy();
    expect(getByText("Map values")).toBeTruthy();
    expect(getByText("Sources")).toBeTruthy();
    // old vocabulary is gone
    expect(queryByText("Match values")).toBeNull();
    expect(queryByText("Wired sources")).toBeNull();
  });

  it("calls onSelect with the mode when a tab is clicked", () => {
    const onSelect = vi.fn();
    const { getByText } = render(
      <ModeStrip modes={["records", "match", "sources"]} active="records" onSelect={onSelect} />,
    );
    fireEvent.click(getByText("Sources"));
    expect(onSelect).toHaveBeenCalledWith("sources");
  });
});
```
