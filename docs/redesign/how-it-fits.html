The rules that connect them

  • Overviews redirect; work surfaces map inline. Dashboard & Sources send you in — Review & Map values do it in place.
  • Same tool, two scopes. Review = Map values across every table, worst-first. Sources = the Sources tab across every table.
  • Sources watches; it never maps. It detects and hands off — the mapping always happens in the cluster-mapper.
  • One gate out. Everything converges on Publish preview, then flows to consumers — Pull API, webhooks, or dim_/map_ for dbt. Nothing publishes by surprise.
  • One word per meaning. “Review” names only the inbox; the pre-publish check is “Publish preview.”
