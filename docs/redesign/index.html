AWhat's hard today

The tab name breaks the product's own vocabularyLanguage

CLAUDE.md and CONTEXT.md both say: avoid "match / matching" — the approved word is mapping. Yet the tab is literally named Match values (ModeStrip.tsx:15). The interface contradicts its own glossary, and "match" collides with the reserved meaning of nothing in particular.

Fix: rename the tab to Map values. It matches the ubiquitous language and reads as an action.

There is no obvious "next action" for a new userClarity

Landing on Match values, a newcomer meets a checkbox, three filter pills, a search box, a badge, a four-column data grid, and a two-tier footer with Undo / Review / Preview SQL / Publish — all at once, all equal weight. The core loop (this raw string → which real record?) is buried in a small editable grid cell.

Fix: lead with one plain sentence and one primary button — "42 values don't have a record yet · Review them one by one." A focused card shows one value, one suggestion, Yes / Pick another / Skip.

Dead and misleading controlsTrust

The Confidence column always renders 0% — the paged payload carries no per-row AI score, so the column is decorative noise. Worse, bulk Accept silently no-ops on every row except the one AI cursor row (MatchModeBody.tsx:449-456): the button looks like it worked and did nothing.

Fix: drop the always-zero column. Surface a suggestion only where one actually exists (inline "Suggested → United States"), and make Accept act on exactly what it shows.

"Wired sources" is an internal metaphorLanguage

"Wired" is engineering slang for the plumbing. The glossary defines a source plainly as "a warehouse column Zugzug scans." A newcomer doesn't know what a "wired source" is.

Fix: name the tab Sources and headline it with a plain sentence: "Where your Country values come from."

Six overlapping status wordsSimplicity

The Standing column speaks six near-synonyms — clean, drift, stale drift, stale, unscanned, not found — plus a coverage bar, an unmapped count, a rows count, and a last-scan time per row. That's a lot of vocabulary for "is there anything to do here?"

Fix: collapse to three states a person can act on — Needs a look, All resolved, Not checked recently — and lead each row with the single number that matters: how many values still need a record.

CPrinciples behind the redesign

  • One job per screen. The screen's whole reason to exist is stated in the first line, in plain words.
  • Say it the way the user thinks it. "This value becomes this record" — not "map raw → canonical target."
  • Spend boldness once. The resolution moment (value → record, with the arrow) is the only loud element; everything else stays quiet.
  • Show suggestions only where they're real. No always-zero confidence, no buttons that silently do nothing.
  • Same word through the whole flow. The tab says Map, the button says Map, the toast says Mapped.
  • Brand untouched. Same tokens, type, and accent as the live app — this is an IA/clarity change, not a repaint.
