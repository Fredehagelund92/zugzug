Zugzug · table toolbar

Six tiers, not eleven buttons.

Same capabilities, re-ranked. One primary action, readouts as gauges, exports folded into a single Data menu, and config demoted to an overflow. Toggle the theme top-right — dark is home, light must hold.

What moved, and why

PublishpromoteThe only accent-filled button. Carries a count badge; falls back to a quiet “Published v3” readout when there’s nothing staged.
StatskeepRestyled as gauges — bold count, muted unit — reading left-to-right like instruments.
Search + SortkeepGrouped as the “view” cluster. Sort (was “Ordering”) becomes an icon beside search.
Undo / RedokeepJoined into one segmented control instead of two loose buttons.
Export CSV · Snapshot · ImportmergeOne Data ▾ menu. CSV = curated records; snapshot (.parquet) = warehouse — labeled so the difference is obvious. Answers “is snapshot needed?”: yes, but not as a top-level link.
Owner · History · Re-scandemoteInto the ⋯ overflow. Owner still surfaces as a chip in context when assigned.
